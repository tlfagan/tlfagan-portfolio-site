Home Assistant

Seabright is a production conversational AI assistant that answers guest questions as the house itself, reducing texts to the homeowner. Safety information — pool rules, emergency contacts, shutdown procedures — is surfaced proactively and never softened.

The assistant has a distinct personality: modern, confident, refined, and slightly snarky. It also carries a set of real house memories — running jokes, family quirks — that surface when context allows, making it feel specific to this place rather than a generic FAQ.

Features in production

Contextual reference photos on answers, live weather/UV/tide conditions panel, shared shopping list, per-answer feedback loop with pre-filled context, and a general notes channel to the homeowner.

Architecture

Static front end deployed via Vercel serverless functions, with the Claude API (Sonnet) handling conversation. The knowledge base started hardcoded in the system prompt and migrated to Airtable, so facts can be updated with no redeploy. A 35-question regression harness runs against the live endpoint before any change ships. Additional integrations include Open-Meteo (weather/UV), NOAA (tides), and Google Forms (feedback). Auth is a custom login page backed by a hashed session cookie (SHA-256 of the shared password, never the password itself) rather than the browser's native Basic Auth popup.
