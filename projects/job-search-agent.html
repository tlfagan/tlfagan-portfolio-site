Job search agent & tracker

A Python automation that sources, scores, and tracks job postings across multiple boards, reducing manual triage to a daily priority list.

Roles are scored against structured fit criteria before reaching the tracker. Claude Haiku handles mechanical steps — fetching, deduplicating, filtering. Sonnet handles scoring and fit analysis. The pipeline runs automatically Monday, Wednesday, Friday, and Saturday at 6am.

Features in production: Multi-source scraping across Adzuna, Remotive, and The Muse. LLM-scored fit filtering with a configurable threshold. Gmail IMAP scanner that flags application-related emails — including soft rejections, using a classifier trained on phrasing like "progressing with other candidates" rather than hard rejection language. Google Sheets tracker updated via Apps Script webhook. On-demand "Today's Focus" generator that surfaces highest-priority actions from the current pipeline state.

Architecture: Python agent orchestrated via GitHub Actions on a scheduled cron. Claude API (Haiku for mechanical steps, Sonnet for judgment-heavy scoring) handles fit analysis. Google Sheets serves as the single source of truth, with a webhook-based write path via Apps Script. Gmail integration runs over IMAP. Deduplication is handled via a seen_jobs.txt log to prevent re-scoring previously evaluated postings.
